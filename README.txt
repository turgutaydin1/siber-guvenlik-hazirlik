KPSS Lisans - 5 Tam Deneme / GitHub Pages Kurulumu

1) GitHub'da yeni bir repository oluşturun (örnek: kpss-deneme).
2) Bu klasördeki dosyaların TAMAMINI repository'nin ana dizinine yükleyin:
   index.html, manifest.webmanifest, sw.js, icon-180.png, icon-192.png, icon-512.png, .nojekyll
3) Repository > Settings > Pages bölümüne girin.
4) Build and deployment > Source: Deploy from a branch.
5) Branch: main, Folder: /(root) seçip Save deyin.
6) GitHub kısa süre sonra https://KULLANICIADI.github.io/kpss-deneme/ biçiminde adres verir.
7) iPhone'da bu adresi Safari ile açın. Paylaş > Ana Ekrana Ekle ile uygulama gibi kullanabilirsiniz.

Notlar:
- Cevaplar ve ilerleme cihazın tarayıcısında saklanır.
- Tüm Denemeleri Sıfırla yalnız bu uygulamanın 5 deneme kaydını temizler.
- İlk ziyaret internet gerektirir. Safari'de site bir kez açıldıktan sonra servis çalışanı önbelleği sayesinde çevrimdışı kullanım da desteklenir.
